3. Se o Android perguntar para permitir instalação a partir do navegador/gestor de ficheiros ("Instalar aplicações de fontes desconhecidas"), confirme a permissão.
4. Abra a aplicação e conceda as permissões de Localização e Contactos.

## ✨ Funcionalidades Principais

- 🗺️ **Mapa Colaborativo em Tempo Real**: Alertas de perigo (acidentes, assaltos, vias cortadas, etc.) sincronizados com o Supabase.
- 🚨 **Modo SOS com Resolução Imediata**: Disparo de alerta sonoro, SMS e WhatsApp para contactos de emergência, com localização GPS precisa e remoção imediata do perigo quando marcado como seguro.
- 🧭 **Navegação & Trajetos Otimizados**: Pesquisa de moradas por proximidade, cálculo de rotas seguras e atalho de navegação rápida para "Casa".
- 🎨 **Interface Material Design 3**: Modo escuro nativo (#111318), tipografia Google Sans/Roboto e botões de alta acessibilidade e contraste.

---

## 🛠️ Tecnologias Utilizadas

- **Framework**: React Native 0.88 / Expo SDK 58 (Expo Router)
- **Design System**: Material Design 3
- **Motor JS**: Hermes Engine
- **Base de Dados / Real-Time**: Supabase
- **Mapas**: React Native Maps
